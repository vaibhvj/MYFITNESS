# StrongTrack AI

StrongTrack AI is a modern AI-powered fitness web app that behaves like a personal trainer.

## Features
- User profile onboarding with goal-based workout + diet generation.
- Dashboard with daily targets and progress bars.
- Auto-generated weekly workout chart with animated demo + live workout mode.
- Live camera posture hints powered by MediaPipe Pose.
- Diet planner with automatic protein target calculation and completion tracking.
- Progress tracker with strength/body metric logging and chart visualization.
- Smart AI automation: intensity adjustment, rep progression, pain-response deloading, notifications.
- AI chat coach, dark mode, printable chart, and PDF export.
- Mobile responsive, clean modern UI.

## Run locally
```bash
python3 -m http.server 4173
```
Open `http://localhost:4173`.
